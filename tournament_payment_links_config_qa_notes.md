# Tournament Payment Link Configuration QA

The live Quickstart configuration shown immediately after format preview includes a dedicated **Optional entry payment links** section between the date and tournament settings. It presents three side-by-side fields for Venmo, Cash App, and PayPal, with direct-host payment guidance and clear helper text explaining club-default prefills and event-level editing.

The section remains optional, leaves the existing Quickstart defaults unchanged, and fits the existing full-screen configuration layout without creating a new wizard step.
