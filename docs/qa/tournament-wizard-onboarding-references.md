# Tournament Wizard Onboarding Reference Notes

## Reviewed patterns

The [ClickUp onboarding flow](https://mobbin.com/flows/52f158f3-6529-4e6a-b936-4f057f4e3136) uses a focused setup decision, restrained surrounding UI, one dominant action, and a clear handoff into the product. Its form presentation supports the proposed single-question progression rather than a dense all-at-once configuration form.

The reviewed [HoneyBook setup screen](https://mobbin.com/screens/7c915d6b-2a99-4eb0-956d-e7a3a97bb265) uses a visible completion count, horizontal progress indicator, ordered task rows, and a subordinate supporting column. These patterns are appropriate for a final Tournament Structure preview: a clear state of readiness, sequenced tournament stages, and a single Create Tournament action.

## Adaptation decisions

The Wizard redesign will retain ChessOTB’s green identity and existing dark/light theme system rather than copying external color palettes. It will use one focused decision per step, an explicit back route, a concise numbered progress rail, 44px-or-larger controls, draft persistence, and a final structure preview that summarizes the chosen format, rounds, player capacity, clock, platform, and rating source before creation.
