# Club Profile Home Typography QA

## Desktop

At 1024px, the Club Home section uses a clearer hierarchy across the “Inside” heading, About card, metadata rows, activity list, members card, and league summary. The larger type remains balanced with the existing card spacing and does not compete with the Club Hero.

## Mobile

At 375px, body copy, labels, metadata, and activity rows remain readable without overlap. Long location and event titles retain truncation or wrapping behavior appropriate to their content role, while action labels remain visible and touch-safe.

## Appearance

The existing light and dark theme text tokens are retained. The refinement increases scale and contrast emphasis without changing Club Home actions, member visibility, or navigation.
