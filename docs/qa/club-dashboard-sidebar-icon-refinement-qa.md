# Club Dashboard Sidebar Icon Refinement QA

## Desktop

At 1024px, the compact left rail retains its 72px geometry and clear active-control state. The OTB!! brand mark is borderless, more prominent, and visually independent from the navigation stack. Navigation icons use consistent 32px rounded icon surfaces, a restrained accent treatment for the active destination, and a modest hover lift without adding unnecessary decoration.

## Mobile

At 375px, the desktop sidebar remains intentionally hidden and the existing mobile header/menu remains the navigation path. The refinement does not introduce a duplicate rail or obstruct the mobile Club Dashboard content.

## Interaction and accessibility

The OTB!! mark remains a named button that returns to all clubs. Existing active-page semantics, keyboard focus disclosure, tooltips in compact mode, and reduced-motion handling remain intact.
