# Repertoire Builder Content Sources

## Lichess Opening Names Dataset

The [Lichess `chess-openings` dataset](https://github.com/lichess-org/chess-openings) provides ECO classifications, English opening names, PGN/UCI move sequences, and EPD positions. Its repository declares a **CC0 Public Domain Dedication**, making it suitable as a factual opening-name and classification enrichment source.

The dataset is appropriate for position-to-opening naming and coverage validation. It does **not** provide original coaching explanations, learning priorities, or proprietary opening evaluations; ChessOTB should retain editorial control over those fields.

Source reviewed: 2026-08-26.
