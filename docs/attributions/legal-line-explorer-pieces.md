# Legal Line Explorer Chess Pieces

The Legal Line Explorer uses the self-hosted **Livius** SVG chess piece set from the `kmar/chess_svg_piece_sets` collection.

The upstream collection identifies Livius as a public-domain piece set. The deployed SVG copies are stored through the project-managed static asset service so board rendering does not depend on a third-party runtime request.

Source: <https://github.com/kmar/chess_svg_piece_sets>
