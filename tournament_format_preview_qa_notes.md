# Tournament Format Preview QA

The live Quickstart journey now pauses after card selection at a dedicated preview. The screen presents the selected title, recommendation badge, real format artwork, a concise setup description, four included defaults, a primary `Use Quickstart` action, and a `Change format` escape path. The preview maintains the tournament wizard's dark-green context while using the warm paper illustration treatment for the selected format.

The primary action was verified in the live wizard. It opens the existing Quickstart form with its established Swiss, 5-round, 16-player defaults, confirming that the preview is a decision gate rather than a new configuration path.
