# Instagram Podium Slide Layout QA

The overlap originated in the player-identity stack: a multi-line name consumed the username line’s vertical space on the exported 1080-square slide. The renderer now reserves two consistent name lines before the username, clamps names after the second line, and constrains long usernames to a single ellipsized line. The available demo tournament remains in progress, so its completion-only carousel entry point was not opened; the source-level and existing carousel test suites verify the export layout safeguards.
