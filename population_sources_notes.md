# Population Intelligence — Verified External Source Notes

- **Archive catalog:** `https://database.lichess.org/standard/list.txt` returned only HTTPS URLs on `database.lichess.org/standard/` with monthly files named `lichess_db_standard_rated_YYYY-MM.pgn.zst`. The newest validated catalog entry observed during Phase 0 was `2026-07`.
- **Checksum catalog:** `https://database.lichess.org/standard/sha256sums.txt` returned lowercase SHA-256 and filename pairs. Production discovery must accept only the strict intersection of the two catalogs.
- **License and retention:** `https://database.lichess.org/` states that the open database is published under Creative Commons CC0. The aggregate design retains no player usernames, game IDs, PGNs, clocks, or archive URLs in application responses.
- **Official population fallback:** `https://explorer.lichess.org/lichess` is the only population Opening Explorer origin used by this feature. The server validates legal UCI paths and serializes standard, speeds, official rating-band lower bound, month window, and bounded response controls.
- **Live endpoint check:** A direct unauthenticated request to `https://explorer.lichess.org/lichess` returned HTTP 401 from this environment on 2026-08-13. After server-only token validation, the same bounded official request returned the expected anonymous aggregate response. The official Lichess API specification identifies `explorer.lichess.org` as the Opening Explorer hostname and requires clients to serialize one request at a time and honor HTTP 429 cooldowns. The application therefore treats non-OK responses as unavailable, never substitutes another host silently, and keeps player evidence unchanged.
- **Operational constraint:** The current managed app runtime is 1 vCPU / 512 MB. The full recent monthly Standard archive cannot be safely imported here, so the implementation must leave the local dataset unpublished and use the strict official Explorer fallback until a separately approved batch environment completes a checksum-verified full month.
